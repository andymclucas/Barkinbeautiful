# MoeGo blocks Groomigo has never heard of — sweep, 02/11/2026

Andy, 02/11/2026: "Do the sweep of MoeGo blocks."

Blockouts do not sync. Groomigo's `staff_blockouts` held nothing but the
Christmas and Australia Day closures, while MoeGo carries **45 blocks**
between 3 November 2026 and 19 February 2027. Online booking is on
(`tenants.online_booking_enabled = 1`) and both `calendar.nextAvailable`
and `calendar.monthCapacity` read blockouts, so every one of these is a
slot Groomigo would currently sell.

## The thing that stops this being a copy-and-paste job

**MoeGo's block feature is used for two different jobs**, and only one of
them is an absence.

Some are people being away. Others are notes to the team pinned to a day
— "Desheds day", "NO MORE FULLY BOOKED", "last day", "first day back".
Mirroring all 45 into Groomigo would mark the salon shut on a day it is
busy, which is worse than the gap it fixes.

So this is a list for Lauren to confirm, not a script to run.
